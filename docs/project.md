# Project

LitSquare Skills makes portable AI Skills understandable to designers and other
knowledge workers. Add a Skill once, organize Skills into Kits, and make them
available to supported assistants without managing hidden folders in the normal
interface.

The app is local-first. It validates and stores content in one canonical library,
never runs bundled scripts, and models changes as reviewable and recoverable
operations. LitSquare Ink MD remains a separate optional editor.

The current M0–M2 milestone covers safe local creation/import and editing. Target
activation, publisher discovery, the public catalog install flow, MCP management,
and signed beta distribution are later milestones.
