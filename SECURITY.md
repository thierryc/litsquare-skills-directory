# Security policy

Report vulnerabilities through GitHub's **Report a vulnerability** private
security-advisory flow for `thierryc/litsquare-skills-directory`.

Do not open a public issue for archive escapes, deletion risks, signature or
digest bypasses, leaked secrets, private-source disclosure, or app/MCP consent
bypasses. Include affected version, impact, reproduction steps, and an inert proof
of concept when possible.

Catalog listing disputes and broken links are not confidential vulnerabilities;
use the public correction form unless private information is involved.
